## O que você encontra

| Área                  | O que mostra                                                                                                                             |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| **Mapa ideológico**   | Sua posição em dois eixos, as correntes ideológicas e as posições editoriais de seis candidatos.                                         |
| **Proposições**       | Perguntas sobre economia, direitos, Estado, ambiente, política externa e atualidades.                                                    |
| **Afinidades**        | As oito correntes e os seis candidatos mais próximos do seu ponto no mapa.                                                               |
| **Eleições 2026**     | Rodadas de pesquisas identificadas por instituto, data, cenário, amostra, margem de erro e fonte, além de resumos dos planos de governo. |
| **Card de resultado** | Uma imagem vertical com seu mapa, a corrente mais próxima e o candidato mais próximo, pronta para baixar ou compartilhar.                |

> [!IMPORTANT]
> A ferramenta é uma **exploração editorial de ideias**. O resultado não é um diagnóstico científico, uma recomendação de voto ou uma pesquisa eleitoral.

## Como usar

1. Abra o [mapa](https://mreaggle.github.io/brasil-politico/) e leia a proposição exibida abaixo dele.
2. Escolha uma das cinco respostas, de **discordo totalmente** a **concordo totalmente**. Se preferir, use **pular**; uma pergunta pulada não conta entre as 30 respostas necessárias para o card.
3. Observe seu ponto se mover. Você pode arrastar e ampliar o mapa, tocar nos candidatos para ler sua classificação e acompanhar as listas de afinidade.
4. Após **30 respostas**, selecione **Criar meu card**. O contador mostra quantas faltam: vermelho no início, amarelo quando faltam 15 ou menos e verde quando o card está liberado.
5. No card, escolha **Compartilhar por apps**, **Baixar imagem** ou **Copiar link**. O link da página também pode ser copiado antes de responder.

Você pode continuar respondendo depois da 30ª pergunta. **Reset** reinicia seu mapa e suas respostas. A página não exige que você responda às 428 proposições.

## Como ler o resultado

O mapa usa dois eixos: **esquerda ↔ direita econômica** na horizontal e **libertário ↔ autoritário** na vertical. Cada proposição tem uma direção e uma intensidade definidas editorialmente. Concordar move seu ponto nessa direção; discordar o move no sentido oposto; uma resposta neutra não desloca o ponto.

As afinidades são calculadas pela **distância entre pontos no mapa**. No ranking das correntes, o percentual também aumenta conforme você responde, até completar 30 respostas. A corrente e o candidato mostrados no card são os mais próximos da sua posição naquele momento. Os percentuais de proximidade pertencem a esse modelo: **não significam chance de voto, apoio político ou concordância com todas as propostas**.

Os pontos e títulos dos candidatos são interpretações dos planos de governo e de falas públicas recentes. Não são posições declaradas pelas campanhas nem endossos. Uma pessoa pode concordar com propostas de candidatos diferentes sem caber integralmente em uma única classificação.

## Eleições 2026 e fontes

A guia **Eleições 2026** mostra nas barras **uma rodada identificada**, não uma média inventada entre institutos. Outras rodadas ficam listadas com links para consulta. Pesquisas feitas em datas, cenários e métodos diferentes não devem ser comparadas como se fossem uma série homogênea.

O recorte atualmente publicado foi atualizado em **24 de setembro de 2026** e reúne levantamentos de Palver, Real Time Big Data, AtlasIntel/Bloomberg, Datafolha e Nexus/BTG Pactual. A guia informa a data de coleta, o tamanho da amostra, a margem de erro, o registro no TSE e a fonte de cada rodada. **Números eleitorais podem mudar; consulte sempre a data e o levantamento original.**

## Privacidade

**O questionário não pede nome, e-mail, documento ou cadastro.** Suas respostas e coordenadas são mantidas na memória da página enquanto ela está aberta; o código atual não as salva no navegador nem as envia a um servidor. Recarregar ou fechar a página reinicia o resultado.

O card é gerado no próprio navegador. Ele só é enviado a outros aplicativos se você escolher compartilhá-lo; também é possível baixá-lo no dispositivo. A página inclui **Google Analytics para métricas de acesso**; isso pode envolver dados técnicos de navegação tratados pelo serviço, mas o conteúdo das respostas não é enviado pelo código do questionário.

## Apoie ou contribua

O botão **Apoiar** abre opções voluntárias de contribuição. Apoiar não altera o resultado nem libera recursos extras.

Encontrou um dado desatualizado, uma pergunta ambígua ou uma classificação que merece revisão? [Abra uma issue](https://github.com/Mreaggle/brasil-politico/issues) com a fonte e uma proposta concreta. Correções editoriais são bem-vindas.

<details>
<summary><strong>Para quem quiser executar o projeto localmente</strong></summary>

O projeto usa React, TypeScript e Vite. Com Node.js instalado:

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

O conteúdo das proposições está em `src/data/questions.ts`; os planos, posições editoriais e pesquisas estão em `src/data/election2026.ts`. O GitHub Pages publica automaticamente a versão gerada quando há um push em `main`.

</details>
